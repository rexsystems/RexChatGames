| | |
|---|---|
| Java | 21 |
| Server | Paper, Purpur, or Folia 1.21 or newer |
| Optional | PlaceholderAPI |

Rewards that run a console command use the same scheduler as the winning player. On Folia, a command that touches another region can fail. Item rewards are given in that player's inventory, and anything that does not fit drops at their feet.

`stats.db` is SQLite, stored in the plugin folder. The driver is packed inside the jar.
